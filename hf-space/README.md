# Rubel Telecom AI Photo Enhancer

This is a separate Hugging Face Space backend for photo upscaling. It does not replace Appwrite or change customer/admin data.

**Deployment note:** Create a new Hugging Face Space with Gradio SDK, then upload the contents of this folder. Free CPU/ZeroGPU usage can be limited and processing can be slow.
